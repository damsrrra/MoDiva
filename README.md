## About

MoDiva is a web platform that brings fashion designers, models, stylists, photographers and makeup artists together in one place. Designers are the primary users: they can showcase their work, rent or sell their garments, find suitable models and collaborate with other creatives. Today, these tasks are spread across several separate platforms.

This project is being developed for the **Agile Team Project (5COSC021C / UoW 5COSC021W)** module at the Informatics Institute of Technology (IIT), in partnership with the University of Westminster.

## Features

| Feature | Description |
| --- | --- |
| Designer portfolio builder | Showcase sketches, illustrations, collections and finished garments |
| AI beginner guidance | Step-by-step guides and a help chatbot for new users |
| AI model-to-product matching | Suggests models whose measurements and preferences suit a garment |
| Personalised recommendations | Relevant models, designers, collections and opportunities for each user |
| Rental and selling marketplace | Designers list original garments for rent or sale |
| Stylist requests | Stylists post the pieces they need, and designers respond with offers |
| Equipment rental | Rent cameras, lenses, lighting, tripods and backdrops |
| Castings and video auditions | Recruiters post castings, and models submit standardised audition videos |
| Creative collaboration | Connect with photographers, makeup artists and stylists |

## Privacy

MoDiva handles personal data such as body measurements and audition videos. These are private by default and shared only with the model's consent, in line with UK GDPR and Sri Lanka's Personal Data Protection Act No. 9 of 2022. Never commit real user data, API keys or `.env` files to this repository.
